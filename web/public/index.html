под капотом

Прокси, который знает подпись

Lane подписывает каждый запрос HMAC-SHA256 и кастомным RC4. Мы повторяем этот алгоритм на сервере — браузер отправляет только обычные запросы к своему же сайту.

Токен — в HttpOnly

JWT после входа шифруется AES-256-GCM и живёт в защищённой cookie. JavaScript страницы его не видит, в localStorage ничего не оседает.

Подпись как в приложении

Три заголовка, канонический query и зашифрованное тело — один в один с BNITManager.cdrl. Поэтому сервер считает запросы «своими».

Без базы и без следа

Никакой БД: сессия живёт в подписанной cookie, ключи — в переменных окружения Vercel. Выйти — значит стереть cookie.
