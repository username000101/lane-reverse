# Перехваченные запросы

Это сырые дампы запросов приложения Lane (`HTTP/2`, `ru.laneapi.com`).
Они полезны как список эндпоинтов и заголовков, но **не как готовые curl-
команды**:

- `x-accept-red: 1` — так ходит само приложение; сервер отвечает
  зашифрованными данными. Для обычного JSON ставьте `0` (см. [../API.md](../API.md)).
- `x-core-token`, `x-client-meta`, `x-request-trace-id` привязаны ко времени
  и уже просрочены. Их нужно генерировать заново через `libbnit.so`.
- `ldi` и `authorization` заменены на плейсхолдеры.

Таблица эндпоинтов и разбор ошибок — в [../API.md](../API.md).
