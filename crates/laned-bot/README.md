# laned-bot — Telegram-бот Lane Music на Rust (`grammers`)

Полнофункциональный Telegram-бот для музыкальной платформы **Lane**, написанный на Rust с использованием MTProto-клиента **`grammers`** и восстановленного механизма подписи запросов `laned-bnit`.

## Возможности

- 🔍 **Поиск треков (`/search <query>`)**:
  - Запросы к `/platforms/search` через подписанный клиент Lane API.
  - Промежуточный индикатор статуса: *«Поиск треков...»*.
  - Выжимка каждого найденного трека: название, исполнитель, альбом, длительность, платформа.
  - Постраничная навигация через **ReplyMarkup** (кнопки с номерами страниц `1`, `2`, `3`...).
  - Кнопка загрузки для каждого трека в списке (`[⬇️ #1]`, `[⬇️ #2]`...).
- 📥 **Скачивание и отправка аудио в Telegram**:
  - При нажатии кнопки скачивания отправляется новое сообщение о статусе: *«Загрузка трека...»* -> *«Отправка в Telegram...»*.
  - Разрешение ссылки на аудиопоток через `/track/stream` (R2/Cloudflare) или прямой стрим SoundCloud.
  - Загрузка аудио через `grammers` и отправка в чат нативным аудиофайлом с заполненными тегами (`title`, `performer`, `duration`, обложка альбома).
  - Удаление промежуточного сообщения со статусом после завершения отправки.
- 📁 **Плейлисты (`/playlists`)**:
  - Список всех плейлистов пользователя (включая *«Любимые треки»*).
  - Интерактивные кнопки для открытия любого плейлиста.
  - Постраничный просмотр треков выбранного плейлиста с кнопками скачивания.
- 👤 **Профиль пользователя (`/profile`)**:
  - Отображение карточки профиля: имя, username, Lane ID, страна, язык интерфейса, количество плейлистов, значок.
  - Инлайн-кнопки для обновления профиля и перехода к плейлистам.
- 🔐 **Официальный флоу авторизации**:
  - Никакого ввода логинов/паролей.
  - Бот генерирует криптографический `deviceId` и отправляет ссылку на официального бота: `https://t.me/lane_music_bot?start=auth<deviceId>`.
  - В фоновом режиме опрашивает `/auth/<deviceId>` до подтверждения.
  - Автоматически связывает токен с Telegram-аккаунтом пользователя и сохраняет сессию.
- 🌐 **Локализация (i18n)**:
  - Поддержка русского (`ru`) и английского (`en`) языков.
  - Автоматическое определение языка из профиля Lane пользователя (`interfaceLanguage`).

## Сборка и запуск

```bash
cargo build --release -p laned-bot
```

### Запуск с токеном бота:

```powershell
.\target\release\laned-bot.exe --token "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"
```

Или через переменные окружения:

```powershell
$env:BOT_TOKEN = "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"
.\target\release\laned-bot.exe
```

### Параметры запуска:

| Флаг | Переменная окружения | Описание |
|---|---|---|
| `--token` | `BOT_TOKEN` / `TG_BOT_TOKEN` | Токен Telegram-бота из @BotFather (обязательно) |
| `--api-id` | `TG_API_ID` | Telegram API ID (по умолчанию 2040) |
| `--api-hash` | `TG_API_HASH` | Telegram API Hash (по умолчанию открытый ключ клиента) |
| `--session` | `TG_SESSION_PATH` | Путь к файлу сессии SQLite MTProto (по умолчанию `laned_bot.session`) |
| `--sessions-file` | `LANE_SESSIONS_FILE` | Путь к хранилищу сессий пользователей Lane (по умолчанию `lane_bot_sessions.json`) |
